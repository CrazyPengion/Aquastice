# Aquastice
A top-down 2D survival game set on an endless ocean, built with Godot.

## Inspiration
One day I found out that two of my friends also liked Raft (by Redbeet Interactive), 
but one couldn’t play it because they had a Mac, and the other had an old Windows laptop that could barely run it.
This coincided with me looking for project ideas to learn Godot, which led to Aquastice: a 2D Raft survival game.

## Goal
The goal of Aquastice is to create a game that captures the vibe of an open-world ocean survival game with base building and 
exploration. It should do all that while running on a potato and including improvements 
I would personally have liked to see in my own Raft playthrough.

The planned gameplay loop is roughly:
1. Collect trash from the ocean manually and eventually automatically.
2. Expand and upgrade your raft and the deployables on it.
3. Explore different locations, such as islands or [feature creep].

One of the main things I was missing in Raft was a real endgame after completing the main story;
my initial ideas to combat this were further deployable upgrades and rarer ores or materials the 
farther you get from your starting point.

Cross-platform multiplayer would be the ultimate goal, but it’s not on the metaphorical roadmap for now, to avoid feature creep.

I mainly use AI to figure out how to do stuff in Godot, since this is my first real project in it. 
All the assets are 100% human slop.
